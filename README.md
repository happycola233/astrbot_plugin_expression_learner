# 表达学习

AstrBot 插件：从群聊里学群友的说话方式，总结成「当某种情境时，用某种表达」，比如「当对价格感到吃惊时：直接说『这么贵』」。回复前挑几条贴近当前聊天的附在请求末尾，让机器人自然地借用。

思路参考 MaiBot 的表达学习，不学黑话。

## 怎么工作

- **收集**：只收「学习的群」里群友发的文字，每个群保留最近 600 条。以下这些跳过：
  - 机器人自己的消息、「学习黑名单」里的人、@机器人的消息、指令；
  - 带链接的、语音转写的（`[语音]` 开头）、合并转发展开的、超过 100 字的。
- **学习**：每攒够一批新消息（「每攒多少条新消息学一次」，且距上次自动学习超过「两次自动学习至少隔几分钟」），带上前面 10 条做语境，交给「学习用的模型」提取最多 5 条。
  - 情境和表达各不超过 20 字，不写人名和专有名词。
  - 「好的」「哈哈」这种谁都会说的不收，没有值得学的就一条不学，不凑数。
- **合并**：
  - 配了嵌入模型时，新学到的说法和已有的按意思比较，相似度达到「合并阈值」就算同一条，次数加一，并记下新的例句（最多 3 句）。
  - 没配时按文字相似度合并。
  - MaiBot 只把一字不差的当成同一条，所以几千条里绝大多数次数都是 1；按意思合并后，次数才能反映哪些说法真的常用。
- **使用**：机器人回复前，用这个群最近几条聊天检索最贴近的说法，按相似度和学到的次数加权随机挑几条（「每次回复带几条」），附在这次请求的末尾。
  - 附加的内容只在这一次请求里，不存进对话历史；也不改系统提示词，不影响缓存。
  - 不额外调用模型来挑，只多一次嵌入请求。
  - 没配嵌入模型时，按次数加权随机挑。
  - 私聊默认也用，从所有学习的群里挑。
- **上限**：每个群超过「每个群最多存几条」后，删掉学到次数最少、最久没学到也没用到的，标了精选的不删。

## 管理页面

在 WebUI「插件」页打开本插件，进入「表达学习」视图：

- 按群查看：已学到、精选、近 7 天新学、待学消息（离下次自动学习还差多少）、上次学习时间，以及嵌入模型的状态。
- 列表可以搜索情境、表达和例句（命中的字会标出来），按最近学到、学到次数、最近带上、最近新学排序，只看精选。最后一列的时间跟着排序方式变。
- 每一条可以标精选、编辑（Enter 保存，Esc 取消）、删除；勾选多条可以一起删。改了文字会重新计算向量。
- 「立即学习」马上学一次；「重建向量」给还没有向量的条目补上（刚配嵌入模型、换了嵌入模型后用），进度会自己刷新；「清空本群」删掉这个群学到的全部内容。删除和清空都会先弹窗确认。
- 跟随 WebUI 的亮色、暗色主题和主题色，窄屏下每一条变成卡片。

## 指令

只有 AstrBot 管理员能用：

| 指令 | 作用 |
| --- | --- |
| `/表达 学` | 马上学一次。在群里只学这个群，私聊里学所有「学习的群」 |
| `/表达 状态` | 每个群学了多少条、精选多少、还有多少消息没学，以及嵌入模型的状态 |

## 配置

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 学习的群 | 空 | 群号，每行一个。不填就什么也不学 |
| 私聊里也用 | 开 | 私聊回复时从所有学习的群里挑。私聊消息本身不学 |
| 学习黑名单 | 空 | QQ 号，每行一个，这些人的消息不拿来学 |
| 学习用的模型 | 空 | 留空就用这个群当前的对话模型 |
| 嵌入模型提供商 ID | 空 | 「模型提供商」里那个嵌入模型条目的 ID，不是模型名。管理页面会列出能用的 |
| 每攒多少条新消息学一次 | `40` | 每次学习调用一次学习用的模型 |
| 两次自动学习至少隔几分钟 | `10` | |
| 每次回复带几条 | `5` | 填 `0` 只学不用 |
| 只用精选的 | 关 | 打开后只从标了精选的里挑 |
| 合并阈值 | `0.9` | 配了嵌入模型时才用。合并得太多就调高，同一个意思存了好多条就调低 |
| 每个群最多存几条 | `5000` | |

## 依赖

只用到 `numpy`，AstrBot 已经自带。嵌入模型可选，不配也能用。
